These files are from the **original Python/Flask + SQLite prototype** before the PHP/MySQL migration.

| File | What it was |
|------|-------------|
| `app.py` | Old Flask backend |
| `inventory.db` | Old SQLite database |

| `logo-source.png` | Full logo image used to generate `php/assets/logo-icon.png` |

Current stack:

- `php/` — web app + API
- `sql/` — MySQL schema
